# songs/

This is the folder the player reads by default. Run `npm start` from the project
root and everything in here becomes the queue.

## The bundled demo tracks

The six MP3s next to this file are **original works generated by this
repository** — there is no sampled or third-party material in them. They are
synthesised from scratch by `scripts/generate-songs.js`: oscillators, a
Karplus-Strong plucked string, drum voices and a feedback reverb, all rendered
offline in pure JavaScript.

They are dedicated to the **public domain (CC0 1.0)**. Use them for anything,
including testing, demos, screenshots and teaching, with no attribution needed.

Each file carries real ID3v2 tags (title, artist, album, track number, year,
genre), which is what the player shows in the "now playing" panel.

### Regenerating them

Rendering is deterministic — the same seed always produces the same audio:

```bash
npm install                 # the MP3 encoder is a dev dependency
npm run generate-songs -- --force
```

Other options:

```bash
node scripts/generate-songs.js --format wav        # uncompressed WAV instead
node scripts/generate-songs.js --only neon-alley   # just one track
node scripts/generate-songs.js --out /tmp/demo     # write somewhere else
```

## Using your own music

Drop any `.mp3`, `.wav`, `.flac`, `.ogg`, `.m4a`, `.aac` or `.opus` files into
this folder (subfolders work too) and press <kbd>F5</kbd> in the player, or just
restart it.

You can also leave this folder alone and point the player at your real library:

```bash
npm start -- ~/Music
music-player ~/Music --shuffle
```

Please keep commercial music out of version control — only add files here that
you have the right to redistribute.
